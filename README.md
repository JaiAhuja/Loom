# 🪡 Loom

> *Weaving threads of knowledge together*

Loom is a local, open-source knowledge graph and AI tutor for researchers,
students, and practitioners. Upload papers, ask questions, and explore shared
concepts and relationships locally with Streamlit, LangGraph, Ollama, ChromaDB,
and Neo4j. No API key is required for the core workflow.

## ✨ Features

| Feature | Description |
|---|---|
| **Local LLM** | Ollama-powered chat and embeddings running on your hardware |
| **Agent orchestration** | LangGraph agent with dynamic RAG and graph-tool routing |
| **RAG** | Docling PDF extraction, ChromaDB storage, and semantic retrieval |
| **Knowledge graph** | Neo4j paper profiles, concepts, methods, findings, and relationships |
| **Graph Explorer** | Pyvis visualization, paper inspection, comparison, and safe queries |
| **Chat history** | Save conversations locally and export them as Markdown |
| **Optional tracing** | LangSmith observability and debugging |

## 🏗️ Architecture

The Streamlit application has three pages:

- `pages/1_Chat.py` — chat, model settings, PDF upload, RAG, and feature toggles
- `pages/2_Knowledge_Graph.py` — graph visualization and paper/concept exploration
- `pages/3_Chat_History.py` — saved conversation search, resume, export, and deletion

Questions flow through the LangGraph agent. It answers directly or calls the RAG
and knowledge-graph tools. Docling converts PDFs to Markdown; ChromaDB stores
searchable chunks; Neo4j stores extracted entities and relationships; and Ollama
generates responses.

Uploads use stable identities: `document_id` comes from the filename, file
storage is content-addressed by MD5, and deterministic keys make re-ingestion
idempotent. Concepts are scoped by domain to avoid collisions across papers.
The agent and Graph Explorer use typed intents and parameterised queries; raw
Cypher is never accepted from users or generated by the agent.

## 📋 Prerequisites

- Python 3.10+
- [Ollama](https://ollama.com/) installed and running
- [Neo4j Desktop](https://neo4j.com/download/) for the optional graph features
- Git
- Approximately 8 GB RAM, depending on the selected model

## 🚀 Quick Start

### 1. Clone the repository

```bash
git clone https://github.com/JaiAhuja/Loom.git
cd Loom
```

### 2. Create an environment and install dependencies

```bash
python -m venv .venv

# macOS/Linux
source .venv/bin/activate

# Windows
# .venv\Scripts\activate

pip install -r requirements.txt
pre-commit install  # optional, enables checks before each commit
```

The single requirements file includes runtime, testing, and development tools.
Run every configured hook with `pre-commit run --all-files`.

### 3. Install Ollama models

Install Ollama, then pull the defaults:

```bash
ollama pull granite4:tiny-h
ollama pull qwen3-embedding:4b  # required for RAG
```

The `docling` dependency can require substantial disk space because of its ML
models. RAG can be enabled after the initial chat setup if needed.

### 4. Configure the environment

Create `.env` in the project root to override defaults:

```dotenv
OLLAMA_MODEL=granite4:tiny-h
OLLAMA_EMBEDDING_MODEL=qwen3-embedding:4b
```

See [Configuration](#configuration) for all supported settings.

### 5. Start Neo4j (optional)

In Neo4j Desktop, create a local Neo4j 5.x database, set its password, and
start it. Loom still runs without Neo4j, but graph features remain unavailable.

### 6. Run Loom

```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser.

## 📁 Project Structure

```text
loom/
├── app.py                    # Streamlit multipage router
├── pages/                    # Chat, Knowledge Graph, and Chat History pages
├── config/                   # Pydantic settings
├── src/domain/               # Shared domain models
├── src/services/             # Agent, ingestion, RAG, KG, LLM, chat, and UI
├── data/                     # Local PDFs, profiles, chat history, and ChromaDB
├── requirements.txt          # Runtime, test, and development dependencies
└── tests/                    # Unit, integration, and end-to-end tests
```

## 🧪 Testing

Run the complete suite:

```bash
pytest -q
```

Run a layer selectively with `pytest -q -m unit`, `pytest -q -m integration`,
or `pytest -q -m e2e`. Tests that require unavailable optional services or
packages skip cleanly.

## ⚙️ Configuration

All settings are read from `.env` through `config/settings.py`.

| Variable | Default | Description |
|---|---|---|
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Ollama server URL |
| `OLLAMA_MODEL` | `granite4:tiny-h` | Chat model |
| `OLLAMA_EMBEDDING_MODEL` | `qwen3-embedding:4b` | RAG embedding model |
| `OLLAMA_TEMPERATURE` | `0.1` | Response temperature |
| `OLLAMA_NUM_CTX` | `32768` | Context-window limit |
| `LANGSMITH_API_KEY` | empty | Optional LangSmith API key |
| `LANGCHAIN_PROJECT` | `Loom` | LangSmith project name |
| `LANGSMITH_TRACING` | `false` | Enable LangSmith tracing |
| `CHROMA_PERSIST_DIR` | `./data/chroma_db` | ChromaDB storage path |
| `OUTPUT_DIR` | `./outputs` | Markdown export directory |
| `RAG_TOP_K` | `5` | Retrieved chunks per query |
| `NEO4J_URI` | `bolt://127.0.0.1:7687` | Neo4j connection URI |
| `NEO4J_USERNAME` | `neo4j` | Neo4j username |
| `NEO4J_PASSWORD` | `Loom-Weave-Threads` | Neo4j password |
| `NEO4J_DATABASE` | unset | Optional named database |

### LangSmith (optional)

Create an account and set these values in `.env`:

```dotenv
LANGSMITH_API_KEY=lsv2_pt_xxxxx
LANGSMITH_TRACING=true
```

## 🔧 Usage

### Chat and RAG

Ask questions directly in the Chat page. For document Q&A:

1. Enable **RAG** in the sidebar.
2. Upload PDFs and process them.
3. Ask questions about the indexed documents.

### Knowledge Graph

Start Neo4j, enable RAG and **Knowledge Graph**, and process PDFs. Loom extracts
paper profiles and links concepts, methods, findings, and cross-paper relations.
Open the Knowledge Graph page for visualization, paper summaries, concepts, and
relationship analysis.

### Chat history

Use **Save Chat to History** to persist a conversation under
`data/chat_history/`. Saved chats can be searched, resumed, deleted, or exported
as Markdown.

## 🧩 Extending the Agent

To add a tool:

1. Create it under `src/services/tools/`.
2. Register it in `src/services/agent/builder.py`.
3. Add any required sidebar toggle in `pages/1_Chat.py`.

Add document formats by extending `DocumentProcessor` in
`src/services/retrieval/processor.py`. Customize agent behavior in
`src/services/agent/nodes.py`.
